# Android APK Build

This project is a Tauri 2 app. The Android project is generated by the Tauri CLI so the source tree stays portable.

## Local build

Prerequisites are documented by Tauri: Android Studio/SDK, Android SDK Platform, Platform-Tools, NDK, Build-Tools, Command-line Tools, Java, Rust, and Android Rust targets.

From the project root:

```bash
npm install
npm run tauri android init
npm run tauri android build -- --apk
```

For smaller per-CPU APKs:

```bash
npm run tauri android build -- --apk --split-per-abi
```

Tauri documents `tauri android init` for initializing the Android target and `tauri android build -- --apk` for producing APKs.

## Important behavior boundary

The app stops at the human checkpoint. It does not contain an automated YouTube engagement click, password collection, proxy rotation, or identity-obfuscation workflow.

## GitHub Actions

The included workflow is a build template. Push the repository to GitHub, then run the Android APK workflow from the Actions tab. A coding AI can further pin/setup exact Android SDK and NDK versions for reproducible releases.
